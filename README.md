# IR-RS-Agent · 开放环境红外遥感处理智能体

> 中国科学技术大学"一〇七杯"算力与智能体开发大赛 · 算力平台赛道参赛作品

面向开放环境的红外遥感**多任务智能体**：用户以自然语言下达指令，智能体自主理解意图、选择并调度专用视觉工具（检测 / 分割 / 识别），完成红外图像分析，并以"自然语言结论 + 结果图"反馈，具备 **任务理解 — 自主规划 — 工具调用 — 结果反馈** 的完整闭环。

本项目定位为**工具编排型智能体**：大模型负责意图理解与工具路由，专用视觉模型负责可靠的检测/分割，而非"训练一个全能模型"。

---

## 一、核心能力

| 类别 | 工具 | 能力 |
|---|---|---|
| 检测 | `ir_detect_closed` | 无人机/地面红外 8 类闭集检测（person/car/bicycle/cyclist/ship/bus/drone/plane） |
| 检测 | `ir_detect_open` | 开放词汇检测（YOLO-World，任意文字类别 + RGB 兜底） |
| 检测 | `ir_ship_detect_satellite` | 卫星三波段热红外海面船舶检测（小目标） |
| 分割 | `ir_segment_cropland` | 遥感耕地/非耕地语义分割（面积占比） |
| 分割 | `ir_segment_vehicle` | 车辆实例分割（掩膜、数量、面积占比） |
| 识别 | `ir_recognize_all` | 开集识别（未指定类别时框出全部目标并生成描述） |

## 二、系统架构

```text
自然语言 + 单张/批量红外图像
        │
        ▼
  ┌─────────────────────────┐
  │  Qwen3.5 条件视觉路由    │  ← 意图理解 + 工具选择
  │  明确任务：文字+元数据     │
  │  模糊任务：文字+元数据+图像 │
  └───────────┬─────────────┘
              │
        ┌─────▼─────┐
        │ 确定性工具守卫│  ← 纠正高风险路由错误（安全护栏）
        └─────┬─────┘
              │
  ┌───────────▼───────────────┐
  │  专用视觉工具层（GPU 推理） │
  │  检测×3 · 分割×2 · 识别×1   │
  └───────────┬───────────────┘
              │
  ┌───────────▼───────────────┐
  │ 统一结构化结果 + 结果图      │
  │ Qwen3.5 自然语言结论        │
  │ 历史对话 / 连续追问 / 导出    │
  └───────────────────────────┘
```

**设计要点**
- **大脑**：Qwen3.5-9B（升级自 Qwen2.5-VL-7B），BF16，`enable_thinking=False`（只输出短小确定的路由 JSON）。
- **条件视觉路由**：任务明确时只靠文字与文件元数据路由，任务模糊时才把图像交给大模型，避免无谓的显存与延迟开销。
- **确定性工具守卫**：在大模型路由后增加一层规则，纠正"RGB 误判为红外""卡车误判为闭集 car""未接入识别却冒充识别结论"等高风险错误。
- **结果自检**：置信度低于阈值时在结论中提示"请人工复核"。

## 三、关键指标

**路由准确率（100 条固定测试集）**

| 阶段 | 路由准确率 | JSON 一次解析 | 工具+参数完全正确 | 平均延迟 | P95 延迟 |
|---|---:|---:|---:|---:|---:|
| Qwen3.5 初始 | 74% | 79% | 74% | 4.19 s | 11.39 s |
| 紧凑 JSON + 条件视觉 | 88% | 100% | 86% | 0.72 s | 1.13 s |
| 强化路由提示词 | 93% | 100% | 92% | 0.68 s | 0.97 s |
| 加入确定性工具守卫 | **99%** | **100%** | **98%** | **0.67 s** | **0.94 s** |

- 100 条测试中，86 条仅用文字+元数据完成路由，14 条因任务模糊启用图像理解。
- **批量性能**：10 张船舶图全流程由约 45.7 s 优化到模型预热后约 9.5 s（保留一次 Qwen 综合分析约 12–14 s）。

## 五、快速开始

**本地版**（详见 `本地部署与使用说明.md`）
```text
1. 双击 安装本地环境.bat         # 创建 .venv
2. 在 .env 填写 DASHSCOPE_API_KEY # Qwen 多模态 API
3. 双击 启动IR-RS-Agent.bat       # 自动打开 http://127.0.0.1:7860
```

**107 平台版**（详见 `107部署/README_107.md`）
```text
1. 上传 deploy_107.tar.gz → 文件管理
2. python3 -m venv venv && venv/bin/pip install -r requirements-107.txt
3. sbatch run_infer.sh            # P107-RTX5090，1×GPU
4. bash demo.sh                   # 一键演示：提交→运行→打印全部证据
```
