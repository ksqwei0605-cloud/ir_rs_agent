# IR-RS-Agent · 开放环境红外遥感处理智能体

> 中国科学技术大学"一〇七杯"算力与智能体开发大赛 · 算力平台赛道参赛作品

面向开放环境的红外遥感多任务智能体：用户以自然语言下达指令，智能体自主理解意图、选择并调度专用视觉工具（检测 / 分割 / 识别），完成红外图像分析并以自然语言 + 结果图反馈，具备"任务理解—自主规划—工具调用—结果反馈"闭环能力。

## 架构

```text
自然语言 + 红外图像
        │
        ▼
  大模型路由层（Qwen）  ← 意图理解 + 工具选择
        │
        ▼
  专用视觉工具层（GPU 推理）
   ├─ 无人机/地面红外 8 类闭集检测（YOLO）
   ├─ 卫星三波段热红外船舶检测（YOLO）
   ├─ 开放词汇检测（YOLO-World）
   ├─ 耕地/车辆分割
   └─ 开集识别（预留）
        │
        ▼
  结构化结果 + 结果图 + 自然语言结论
```
